# syncGaroonToGoogle

Garoonの予定をGoogle Calendarへ同期するプロジェクトです。

| 実装               | コードの入口                           |
| ------------------ | -------------------------------------- |
| Chrome拡張機能     | [chrome-extension/](chrome-extension/) |
| Google Apps Script | [gas/](gas/)                           |

利用手順と設計の入口は[ドキュメント一覧](docs/README.md)です。利用する実装を選び、[ユースケース一覧](docs/procedures/use-cases.md)から必要な操作へ進んでください。
