# GAS版の項目変換

GAS版の保守担当者が、Garoon予定からGoogle Calendarへの変換を確認するための仕様です。[GaroonEventService](../../gas/src/service/ScheduleEventService/GaroonEventService.js)と[GCalDao](../../gas/src/dao/GCalDao.js)を実装の確認先にします。

## タイトルと説明

| 入力 | 出力 | 変換 |
| --- | --- | --- |
| `eventMenu`と`subject` | タイトル | `【eventMenu】subject`。メニューがなければ件名だけ |
| `attendees[].name` | 説明の参加者欄 | 氏名の全角スペースを置換し、半角コンマとスペースで結合する |
| `notes` | 説明のメモ欄 | 本文と改行を転記する |

説明は次の形式で生成します。

```plaintext
【参加者】
田中 太郎, 佐藤 花子

【メモ】
Garoonのメモ本文
```

参加者は招待先として登録しません。招待メールを発生させないため、説明欄のテキストとして扱います。

## 日時

| 入力               | Google側の扱い                                  |
| ------------------ | ----------------------------------------------- |
| 通常の時刻指定予定 | `dateTime`をDateへ変換して開始と終了に使う      |
| `isAllDay`         | 終日予定を作成する                              |
| 終日予定の終了     | Garoonの終了日時へ1秒加え、翌日の境界へ合わせる |
| `isStartOnly`      | 終了日時に開始日時と同じ値を使う                |
| 繰り返し予定       | 取得した各回を独立した予定にする                |

開始時刻だけの予定は、現実装では開始と終了が同じです。終了時刻の補正を行わず、同じ日時をCalendarAppへ渡します。

## 管理タグ

| タグ                     | 値                                  | 目的       |
| ------------------------ | ----------------------------------- | ---------- |
| `GAROON_UNIQUE_EVENT_ID` | 通常は`id`、繰り返しは`id-repeatId` | 予定の照合 |
| `GAROON_SYNC_DATETIME`   | Garoonの`updatedAt`                 | 更新の判定 |

更新日時の比較は秒単位で行います。管理タグが欠けるか、保存された同期日時が無効なら更新対象です。Garoon側の更新日時が無効な場合は、その予定の更新をスキップします。

## 同期先と除外

タグは`notes`から`#(\\w+)`の形式で抽出します。大文字小文字を区別せず、登録されたカレンダー名と照合します。

- `#nosync`がある場合は他のタグより優先して除外する。
- 一致するカレンダー名が複数ある場合は、メモで最初に現れたものを使う。
- 一致しない場合は既定のカレンダーへ登録する。

`#nosync_extra`のような別のタグを、`#nosync`の部分一致として除外する仕様ではありません。

## 転記しない情報

| 入力           | 扱い                                               |
| -------------- | -------------------------------------------------- |
| `eventType`    | 文字列自体は転記せず、日時と終日フラグで予定を作る |
| 施設           | 招待先として登録しない                             |
| 公開範囲       | Google側の共有範囲へ自動変換しない                 |
| 会社情報       | 転記しない                                         |
| 添付ファイル   | 転記しない                                         |
| 繰り返しルール | 各回を独立して扱うため設定しない                   |

公開範囲と共有先はGoogle Calendar側で確認してください。
