# GAS版を変更するときの注意

GAS版を変更するAIが、初期化と外部反映の落とし穴を確認するための指示です。[共通方針](maintenance.md)を適用します。

## 読み込みと初期化を変更する場合

Apps Scriptのソースはグローバル定義で読み込まれます。`import`と`export`を導入しないでください。一般的なES Modulesへの変更は、実行方式まで変えるため通常の整理とは分けて扱います。

サービス間に遅延設定の参照があります。[設計](../design/gas-design.md#クラスの責務)を読み、依存関係の生成順と未設定時の検証を保ちます。

## 設定を変更する場合

ScriptPropertiesのキーを変更したら、定数と取得処理を確認してください。設定例の更新漏れも確認します。値をファイルへコピーすることと、設定関数を実行して保存することは別です。

手順は[GAS版の準備](../procedures/gas-setup.md)へ置きます。AI向け文書に認証と配備の別手順を作りません。

## 検証と配備を変更する場合

この実装の`npm test`は未設定です。成功した自動テストがある前提で結果を報告しません。

取得の上限に達したときの扱いは、完全取得を要求する実装とは異なります。差分処理の変更では[GAS版の制約](../requirements/gas-requirements.md#制約)を確認します。

認証と配備は既存の公開スクリプトを使い、同じ操作のrawコマンドへ置き換えません。実際の反映はユーザーの承認範囲で行います。
