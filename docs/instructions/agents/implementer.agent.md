# コードの変更

[共通方針](../maintenance.md)に従って、承認された範囲を実装します。

1. 変更する実装の指示と設計を読む。
1. 公開される動作を保ち、状態の保持と値の変換を適切に分ける。
1. 必要な回帰テストを実行する。
1. 振る舞いを変えた場合は、所有する文書の更新箇所を報告する。

完了時は次を返します。

- 変更後の動作と理由
- 検証結果
- 実環境で未確認の範囲

hookの存在だけで検証済みとしません。
