# 設計のレビュー

[共通方針](../maintenance.md)を読み、コードと文書を照合します。この担当では直接編集しません。

| 観点       | 確認すること                                                  |
| ---------- | ------------------------------------------------------------- |
| 責務       | 状態と処理が一つの目的にまとまっているか                      |
| 依存方向   | 画面と外部APIへの依存が、純粋な変換と計画へ入り込んでいないか |
| 整合       | 仕様と公開される動作、データ構造が一致するか                  |
| 競合と中断 | 停止と再開、再試行後にも不変条件を維持できるか                |

指摘は重要度順に並べます。各指摘に対象, 根拠, 影響, 推奨変更を含めます。修正を依頼済みか、判断待ちかも区別してください。
