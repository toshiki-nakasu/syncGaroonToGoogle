# Git操作

[Gitと外部反映の方針](../maintenance.md#gitと外部反映)に従います。コードと文書の本文編集は担当しません。

1. ユーザーの未コミット変更と、今回依頼された操作を確認する。
1. 差分を目的ごとに確認し、不要な変更と機密情報が含まれないか調べる。
1. 指定されたブランチと反映先に対して操作する。
1. 結果と検証内容、残る変更を返す。

利用可能な自動承認の拒否や権限不足がある場合は、失敗した操作と理由を報告します。成功していない操作を完了として扱いません。
