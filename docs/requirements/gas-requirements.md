# GAS版の要件

GAS版の利用者と保守担当者が、対応範囲と実行条件を確認するための仕様です。実行は[GAS版の操作](../procedures/gas-operations.md)を参照してください。

## 対応する機能

| 機能 | 対応 |
| --- | --- |
| GaroonからGoogle Calendarへの同期 | 対応 |
| Google CalendarからGaroonへの逆方向同期 | 未実装 |
| 自分の在席情報リセット | 対応 |
| Garoonのパスワード認証 | 対応。2要素認証が必要なユーザーでは利用不可 |
| 時間主導型トリガー | Apps Script側で設定する |

Garoon予定の作成と削除には補助メソッドがありますが、通常の一方向同期でGaroonの予定を書き換えることはありません。補助関数による一括削除の利用手順は未整備です。

## 設定の責務

設定キーと値の形式は[設定例](../../gas/src/properties/ScriptProperties.example.js)を正本とします。

| 設定         | 用途                                       |
| ------------ | ------------------------------------------ |
| 接続情報     | Garoonのドメインと認証ユーザーを指定する   |
| プロファイル | 予定を取得する対象を指定する               |
| 実行時間帯   | 同期を実行できる時間帯を指定する           |
| 同期期間     | 過去と未来の検索範囲を指定する             |
| カレンダー名 | 一致するタグがない予定の登録先を指定する   |
| 振り分け先   | タグとして使うカレンダー名の配列を指定する |

カレンダーは自分が所有する同名のものを検索し、なければ作成します。タグ名は登録したカレンダー名と照合します。メモに複数の一致するタグがある場合は最初のものを採用します。`#nosync`は最優先で除外します。

## 照合と変換

予定は`GAROON_UNIQUE_EVENT_ID`で照合し、Garoonの更新日時を`GAROON_SYNC_DATETIME`へ保存します。手動作成の予定でこの識別子がないものは、通常の同期の削除対象にしません。

変換の詳細は[項目変換](../design/gas-event-mapping.md)を参照してください。

## 制約

- 実行時間帯の外では同期をスキップする。
- Google側への反映はトランザクションではなく、途中まで変更されて失敗する場合がある。
- APIの取得ページ数には上限がある。
- 取得上限に達した場合、GaroonのDAOは警告を出して取得済みの予定を返す。

取得上限の警告がある状態では、全件取得済みとは判断しません。対象期間を短くし、手動で結果を確認してから定期実行を再開してください。

## 在席情報リセット

`resetPresence()`は認証ユーザーの在席ステータスコードとメモを空文字列へ戻します。他のユーザーを指定する画面と一括リセット機能は提供しません。
